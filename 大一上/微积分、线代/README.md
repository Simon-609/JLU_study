两门公共数学课。
微积分a1，难度较大，可以跟老师听，或者参考b站，算是全网统一的课程。
b站较不推荐宋浩老师的课程，讲解内容较为简单。
刷题：
1.标准化作业（必做），每年很多原题直出。
2.历年真题（必做），熟悉吉大的出题方式和历年考点。
简单年份刷完这俩即可满绩，但a1近几年出题水平浮动较大，有些年份只刷这两项还需要一点运气。
稳满绩：
1.平时学有余力可以刷习题课教程
2.历年考研数一数二定积分之前的内容，蛮有参考价值的，很多期末难题（比如概念辨析）都是考研原题或者改编的。
3.汤家凤1800，这个也是考研题。
综上在难题年份，想稳满绩且学有余力，可以三选其一刷（很多内容都是重叠的，刷一本足够）。
线代，较为简单的一门公共课。
刷作业和历年真题就够了，其中作业和历年真题中有一些技巧性和难度的题也是历年考研题的改编。
所以按照考研数学的难度学吉大计软的公共数学一定能满绩，而且也只有某些年份达到了这个难度。
重点：作业和历年真题
