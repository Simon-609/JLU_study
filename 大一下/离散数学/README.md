大一下较难的专业课
课程参考较少，推荐学在吉大欧阳丹彤老师，为数不多讲解清楚明了的老师。
此仓库收集的离散1应该是比较全的了。
学习指导
1.听课，看懂ppt，考察接近对过程的理解。
2.刷老师给的课堂练习，小测，
3.可以参考计院的近年真题。
4.解忧历年真题，考试小题难度比这个难度，大题白给分的难度接近，证明题难度不同年份差距较大。
必会历年真题最简单的几道大题（45分），看懂ppt非证明部分，小题（30分，难度较高），ppt证明部分（25分，难度较高）。
证明部分多考数论和图论，多写，即使是思路，大家都不会的给分很松，小题直接写出结论即可，要说明原因的再写原因。证明题可参考ppt的证明和课后题
